# pannkaka-html

Ett enkelt statiskt HTML-projekt.

## Beskrivning

Detta projekt innehåller en enkel webbsida i `index.html` och är byggt för att kunna köras direkt i en webbläsare utan några externa byggverktyg eller beroenden.

## Struktur

```text
pannkaka-html/
├── index.html
├── README.md
└── (eventuella framtida filer eller mappar)
```

## Hur du öppnar projektet

1. Öppna `index.html` i din webbläsare.
2. Alternativt kan du starta en lokal webserver om du vill köra sidan via `http://localhost`.

Exempel med Python:

```bash
cd "C:/Users/patri/pannkaka-html"
python -m http.server 8000
```

Sedan öppnar du:

```text
http://localhost:8000
```
